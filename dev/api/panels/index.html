Panels, observation & masks

Wide longitudinal panels (CDMPanel), observation bridges mapping latent states to measured columns (ObservationBridge), and missingness masks (ObservationMask). For conceptual background on missingness identification and handling, see the Missingness guide.

Wide panels

CausalDynamics.CDMPanel — Type
CDMPanel

Wide observational panel from $n$ independent DiscreteTimeCDM trajectories of length $T$.

Fields

  • n, T: dimensions
  • data: column name → length-n vectors
  • column_order: stable column order for table conversion
  • variables: endogenous symbols from the CDM
  • baseline, timed, terminal: role partition used when building columns
  • temporal_spec: optional TemporalDAGSpec for downstream ID

CausalDynamics.check_time_resolution — Function
check_time_resolution(query, measured_at; warn=true) -> Vector{NamedTuple}

Check whether a TemporalEffectQuery references variables at time indices that differ from where they were actually measured in the wide panel.

measured_at maps DAG node symbols to the time index of the wide column that holds the value (e.g. period-constant contact scores measured once at $t = 1$ but referenced at t_outcome = 4).

Returns a vector of issue records; emits @warn when warn=true.

CausalDynamics.simulate_panel — Function
simulate_panel(cdm, n, T; rng, intervention, baseline, timed, terminal, name_fn, temporal_spec)

Simulate n independent trajectories and stack them as a wide CDMPanel.

For observational estimation (CausalTargeted sequential LMTP), leave intervention = nothing so treatments follow the natural mechanism.

Keyword arguments

  • baseline: symbols emitted once (value at $t = 1$), e.g. [:w]
  • timed: symbols expanded as name_fn(v, t) for $t = 1:T$; default is all endogenous variables not listed in baseline or terminal
  • terminal: symbols emitted once from time index $T$ (bare name), e.g. [:y]
  • name_fn: (var::Symbol, t::Int) -> Symbol (default panel_column_name)
  • temporal_spec: optional lag DAG carried for ID hand-off
source

Observational panels (estimation hand-off)

simulate_panel stacks n natural trajectories into a wide CDMPanel for sequential LMTP. Column roles:

  • baseline — bare symbol, value at $t = 1$ (e.g. :w)
  • timed — panel_column_name(v, t) → :a1, :a2, …
  • terminal — bare symbol at occasion $T$ (e.g. :y)
using DataFrames

panel = simulate_panel(
    cdm, 200, 2;
    baseline = [:w],
    timed = [:a, :l],
    terminal = [:y],
)
df = DataFrame(NamedTuple(panel))  # or DataFrame(panel) when CausalDynamicsDataFramesExt is loaded

Leave intervention = nothing for observational estimation. Interventional Monte Carlo effects stay on g_computation in Discrete-time CDMs; CausalTargeted consumes df via sequential_spec_from_identification / execute_estimand.

Observation bridges

CausalDynamics.ObservationBridge — Type
ObservationBridge(mapping; measure=nothing, availability=nothing)

Declare how latent (or endogenous) series become estimation columns.

Fields

  • mapping: when measure is nothing, source series symbol → panel symbol; when measure is set, optional rename of measure output keys → panel symbols (missing keys keep their measure names)
  • measure: optional (state_nt, t) -> NamedTuple producing observed values from the full endogenous state at time t
  • availability: optional map from panel (or source) symbol to the earliest decision time $t$ at which the quantity enters $ℋ_t$. A quantity may describe an earlier realisation and become available later.

Latent → observed panels

When latents are inferred outside CausalDynamics (filter, smoother, EM), map them with ObservationBridge and panel_from_latent_series. No Kalman/particle code lives here—only the typed hand-off to wide panels.

bridge = ObservationBridge(
    Dict(:y_hat => :y);
    measure = (state, t) -> (y_hat = state.x,),  # e.g. use latent x as assay
)
panel = panel_from_latent_series(
    inferred_units;  # Vector{<:Dict} of series
    bridge = bridge,
    timed = [:y],
    terminal = Symbol[],
)

Observation masks and missingness mechanisms

CausalDynamics.ObservationMask — Type
ObservationMask

Binary response indicators aligned with named columns.

Fields

  • columns: column symbols (one per mask column)
  • observed: n × length(columns) bit matrix; true means R = 1 (observed)
  • time_indexed: if true, columns are time steps of a timed process (e.g. :y1, :y2)

CausalDynamics.apply_missingness_mechanism — Function
apply_missingness_mechanism(data, spec; intercept, coefficients, rng)
    -> (Dict{Symbol, Vector}, ObservationMask)

Generative incompleteness for Dynamical × L2 oracles: start from complete columns and set spec.response entries to missing under

  • :mcar — Bernoulli with success probability $\mathrm{logistic}(\mathrm{intercept})$ of being missing
  • :mar — $P(R=0 \mid W) = \mathrm{logistic}(\mathrm{intercept} + \beta'W)$
  • :mnar — throws (not simulated without further assumptions)

coefficients defaults to 0.8 for each symbol in spec.conditioning_set. Returns a new column dictionary (response columns become Union{Missing,Float64}) and the corresponding ObservationMask.
